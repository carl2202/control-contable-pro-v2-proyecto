# Propuesta del proyecto

Copia aquí el contenido de tu propuesta aprobada por el docente (puedes pegarla desde Word).

Asegúrate de incluir, como mínimo:
- El problema y el cliente objetivo.
- Los roles.
- Las funcionalidades obligatorias, la funcionalidad estrella y las mejoras opcionales.
- Lo que está **fuera del alcance**.
- El plan de entregas.
